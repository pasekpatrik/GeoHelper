# GeoHelper
GeoHelper je minimalistický webový nástroj pro nadšence do geocachingu. Aplikace slouží k rychlé vizualizaci souřadnic v terénu a efektivní evidenci nalezených pokladů.

[Spustit aplikaci GeoHelper](https://helpgeo.netlify.app/)

### Klíčové vlastnosti
 * Interaktivní navigace: Okamžité zobrazení vložených souřadnic na mapě.

 * Potvrzení nálezu: Možnost označit nalezenou kešku doprovázená zvukovou signalizací.

 * Personalizace: Snadná správa zvukových upozornění (zapnutí/vypnutí) v nastavení aplikace.

 * Mobilní optimalizace: Plně responzivní rozhraní pro bezproblémové použití na smartphonech přímo v terénu + PWA.

## Instalace závislostí
```bash
npm install
```

## Rozběhnutí lokálního serveru
```bash
npm run dev
```
